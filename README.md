# Digestiva · Enfermedades del sistema digestivo

Web interactiva y divulgativa sobre el aparato digestivo y sus enfermedades más frecuentes.

- **Mapa anatómico**: toca un órgano para ver su función y sus enfermedades.
- **Recorrido de un bocado**: de la boca al recto, con tiempos aproximados.
- **Catálogo** de 25 enfermedades con búsqueda, filtros y ficha (síntomas, causas, diagnóstico, tratamiento).
- **Señales de alarma** y **quiz** de mitos y realidades.
- Modo claro/oscuro y diseño adaptable a móvil.

Es un sitio estático: abre `index.html` en el navegador (o publícalo con GitHub Pages).

> Contenido educativo. No reemplaza la consulta médica.
